# ORIGINAL VAULT

Global Fashion Marketplace

## Sobre o projeto
ORIGINAL VAULT é uma plataforma internacional
de compra e venda de moda.

## Funcionalidades planeadas
- Marketplace de moda
- Lojas para vendedores
- Perfis de compradores
- Catálogo de produtos
- Pesquisa e filtros
- Carrinho de compras
- Chat entre compradores e vendedores
- Painel de administração
- VAULT DISCOVER
- VAULT REELS
- VAULT LIVE
- Carteiras VAULT BUYER e VAULT SELLER

## Plataformas
- Website
- Android
- iOS

## Tecnologias planeadas
- Next.js
- TypeScript
- React Native
- PostgreSQL
- Prisma
